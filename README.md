## Käyttöohje

# Ohjelman asentaminen ja suorittaminen

Kloonaa projekti ja siirry sen juurikansioon.

Asenna projektin riippuvuudet Poetrylla:

poetry install

Käynnistä ohjelma Poetryn virtuaaliympäristössä Windowsissa:

poetry run python src\main.py

Ohjelman käynnistyttyä kirjoita lasku kehotteeseen "Anna lauseke:"

Hyväksytyt laskut voi nähdä jos syöttää "apua"
